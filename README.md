## Overview

AI-generated search results often present information as long-form summaries, which can be difficult to scan, compare, and act on. This is especially challenging for exploratory queries like “things to do in NYC,” where users are evaluating multiple options.

This project explores how AI-generated answers can evolve from static text into interactive, structured experiences.

## Approach

Rather than expanding into more text or transitioning into a conversational interface, this prototype keeps users in the search results context and transforms the answer itself into an explorable system.

The design focuses on:
- **Scannability** through visual grouping and hierarchy  
- **Exploration** through swipeable, card-based modules  
- **Decision support** through lightweight shortlisting  

This reframes search from information consumption → decision-making.
